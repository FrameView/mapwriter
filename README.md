mapwriter
=========

MapWriter: A minimap mod for Minecraft 1.8.9


Instructions for development with IntelliJ IDEA software:

1) Make sure to use IntelliJ IDEA 2021.1 and Java 8.

2) Run the 'setupDecompWorkspace' task with '-Xmx4g' argument inside the VM options.

3) Run the 'build' task and reload the project. 

4) You should now be able to add features and test by using the 'runClient' task :)
